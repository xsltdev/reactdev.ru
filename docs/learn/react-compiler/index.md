# React Compiler

## Введение {#introduction}

Узнайте, [что делает React Compiler](introduction.md) и как он автоматически оптимизирует приложение React, беря мемоизацию на себя и избавляя от необходимости вручную писать `useMemo`, `useCallback` и `React.memo`.

## Установка {#installation}

Начните с [установки React Compiler](installation.md) и узнайте, как настроить его вместе с инструментами сборки.

## Постепенное внедрение {#incremental-adoption}

Изучите [стратегии постепенного внедрения React Compiler](incremental-adoption.md) в существующей кодовой базе, если вы ещё не готовы включить его повсюду.

## Отладка и устранение неполадок {#debugging-and-troubleshooting}

Когда что-то работает не так, как ожидалось, воспользуйтесь [руководством по отладке](debugging.md), чтобы понять разницу между ошибками компилятора и проблемами во время выполнения, распознать типичные ломающие шаблоны и пройти системный процесс отладки.

- [Директивы](../../reference/react-compiler/directives/index.md) — управление компиляцией на уровне функций
