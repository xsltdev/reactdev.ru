# Серверные Actions

<big>Серверные Actions теперь описаны как [серверные функции](server-functions.md).</big>

До сентября 2024 года серверные функции назывались Server Actions. Если серверная функция передана в проп `action` или вызвана изнутри действия, это серверное действие, но не все серверные функции являются действиями. Актуальный текст — в статье [Серверные функции](server-functions.md).
